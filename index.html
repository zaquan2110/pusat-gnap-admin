Arsip & Administrasi Surat GNAP

Isi data pokok surat dan unggah dokumen resminya. Tidak perlu menulis ulang isi surat di dashboard.

Maksimal 15 MB. File akan disimpan di penyimpanan GNAP.

Integrasi Sistem

Database: Supabase GNAP. Publikasi portal menggunakan tabel gnap_members yang hanya dapat dibaca publik untuk data yang sudah diterbitkan.

Discord: hubungkan Edge Function bernama publish-gnap-card dan simpan Discord webhook sebagai secret di server, bukan di halaman ini.

Jangan memasukkan service_role key atau URL webhook Discord ke kode frontend.
